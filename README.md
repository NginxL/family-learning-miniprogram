# 小小日课 · Family Learning

微信原生小程序 + 腾讯云开发 CloudBase 的家庭学习 MVP。支持家人共同照看孩子、每日古诗文与英语任务、打卡及跨设备同步。

**默认启动为本机演示模式。云端版本需要配置自己的 AppID、云环境并部署云函数；仅导入代码不会启用真实多手机同步。**

## 当前功能

| 场景 | 行为 |
|---|---|
| 家庭成员 | 创建家庭、一次性邀请码加入、创建者移除成员、成员退出 |
| 孩子档案 | 最多 5 个孩子；年龄、在读年级可填写和编辑，家人共享 |
| 每日任务 | 古诗文、单词、句子、英文阅读、读书、数学可分别设置数量和全新／复习；支持手动添加 |
| 今日打卡 | 按学习类型折叠显示，一组一个完成／撤销入口；每个单词和每篇内容仍保留独立学习记录 |
| 知识库 | 本地搜索、按内容类型／课标范围／已核实教材年级筛选，加入今日学习；上海中考页显示官方依据与当前缺项 |
| 学习回顾 | 查看学过和家长确认掌握的内容，再次安排到今日复习；日期记录支持近一年 |
| 知识进度 | 年龄、在读年级和学习进度分别展示；家长标注与教材已核实范围分开统计 |
| 同步 | 打卡先持久化；联网、打开应用和前台每 20 秒同步；重复请求去重，冲突提示重新确认 |

内置 156 项古诗文原作参考（含组、节选）、1,677 项英语词汇、12 句自编口语、6 篇亲子阅读和 20 道加法练习。古诗文含国家课标 135 篇／组；英语含主表 1,600 词条组（其中二级带星词 505）及另列表 77 项。基础 505 词提供自编常用义，其余是通用词典参考。

英文文章可在「计划 → 家长添加 → 英文阅读」中录入，安排到今日或加入自动内容库；当前没有内置英文文章库。今日进度按完成的学习类型统计，知识回顾和年级进度仍按具体内容统计。

**知识库仍不是上海中考或各年级的完整教材库。** 当前核实 29 个年级映射：一上公开样本 6 项、三上公开样本 11 项、六上官方目录 10 项、七上官方目录 2 项；各册全量、上海英语单元词表、学校实际版次及正文逐字校对待确认。已核实范围显示计数，缺少完整分母时不显示整年级完成率。详见[知识库与年级核验](docs/知识库与年级核验.md)、[上海中考范围与缺项](docs/上海中考知识范围与覆盖.md)和[版本边界](docs/MVP.md)。

## 本地运行

需要 Node.js 20+、微信开发者工具。

```sh
npm ci
npm ci --prefix cloudfunctions/familyApi --ignore-scripts
npm run configure
npm run build
npm run verify
```

微信开发者工具打开仓库根目录（包含生成的 `project.config.json`）。未设置 AppID 时可使用测试号／游客模式。进入「家庭」创建演示家庭，再到「今日」查看和完成任务。演示数据保存在本机，不能邀请真实家人。模拟身份只存在演示和测试中，生产函数只使用微信提供的 `OPENID`。

## 接入云开发

```sh
npm run configure -- --appid wxYOUR_APP_ID --env YOUR_CLOUDBASE_ENV_ID
```

占位参数应替换成真实编号。命令生成被 Git 忽略的配置。按[部署说明](docs/DEPLOYMENT.md)建立数据库集合及规则，部署 `familyApi`，再进行两个微信账号的实机验证。

公共仓库不包含真实 AppID 配置、AppSecret、上传私钥、访问密钥、邀请码或家庭记录。云函数使用运行时身份访问数据库，无需将云密钥放进代码。

## 工程结构

```text
miniprogram/                 微信页面、演示模式、同步队列
cloudfunctions/familyApi/    家庭权限、任务与事务 API
cloud/database.rules.json   集合的客户端拒绝读写规则
tests/                      家庭隔离、冲突、离线重试和 SDK 契约测试
shared/                     客户端与云函数共用的选材、回顾、进度规则
data/catalogs/              课标目录、原作、词表与教材证据
scripts/knowledge.js        从源数据生成内置知识库
docs/                       部署、边界与调研来源
```

`npm run verify` 检查 JS/JSON、页面入口、包体和核心测试；`npm audit --prefix cloudfunctions/familyApi --omit=dev` 检查部署依赖。GitHub Actions 执行同样检查。测试使用隔离内存事务和两个独立客户端缓存，不等于真实云环境或真机验收。

修改 `shared/` 或 `data/catalogs/` 后运行 `npm run build`；生成结果随代码提交，检查脚本会拒绝客户端／云函数不一致的版本。

源码公开可读。第三方内容许可见[数据来源与许可](data/catalogs/README.md)；课本、配音和现代注释没有随源码打包，家庭数据只保存在家庭自己的环境中。
