英文原始参考保留转录页码、列号、PDF SHA-256、ECDICT 版本及 CSV SHA-256。运行时优先使用基础词自编释义；60 个亲子入门词沿用自编词卡。源 JSON 保留原始词典参考，不能把里面的专业义或少用义直接当作教材释义。

原作转录参考 [aopao/chinese-gushiwen](https://github.com/aopao/chinese-gushiwen/tree/c2345d0abf2404b8b3601e4afc2e8fd12f90d6c8)，固定版本 `c2345d0abf2404b8b3601e4afc2e8fd12f90d6c8`。该仓库未声明整体开源许可；本库使用的对象为已进入公版的古代原作，不继承或声称拥有该仓库现代编辑内容的许可。

朝代标签按内容ID与转录记录匹配；部分补充篇目按同一作者归属核对。`source_record`表示转录元数据，`author_period`表示作者时代依据，`reviewed`表示另附核对来源，`unresolved`表示待考；这些状态不等同于校内教材核准。诸葛亮由原始错误的“两汉”改为“三国·蜀汉”；《司马光》的“元代”指《宋史》编纂时代，不能误作故事人物的生活年代。《礼记》《战国策》区分材料时代与编纂时代，《列子》保留今本成书争议；未署作者的《画》标为“朝代待考”。具体证据与说明保存在该JSON，页面展示需要保留的争议说明。

ECDICT 来源：[skywind3000/ECDICT](https://github.com/skywind3000/ECDICT)，固定版本 `bc015ed2e24a7abef49fc6dbbb7fe32c1dadaf8b`。Copyright (c) 2025 Linwei，MIT License；完整许可保留在 [licenses/ECDICT-MIT.txt](../../licenses/ECDICT-MIT.txt)。这里只提取课标所需的参考释义，不分发整个词典 CSV。

现代课本整册、课文中的现代作品、扫描 PDF、录音及注释没有进入本仓库。源码公开不改变这些材料的权利归属。小程序保留官方阅读入口和事实性书目信息。

## 生成与校验

自编语文短文维护在`src/shared/catalog.ts`，新增英语短文及读后问题维护在`src/shared/reading-catalog.ts`，均按稳定ID接入知识库和任务。`src/miniprogram/lib/pinyin-data.ts`保留原有21项注音；`scripts/lower-primary.js`按一至五年级源数据生成另外169项注音，客户端仅为完全匹配的文字显示拼音。内容范围、标调与剩余核验事项见[阅读与拼音](../../docs/阅读与拼音.md)。

`npm run build` 从上述源数据生成 `shared/knowledge-data.json`、`shared/resources.json`，云函数使用同样的 JSON 文件，小程序使用对应的 `.js` 数据模块，以兼容微信原生模块加载；构建时合并重复字符串与对象键布局，导出值与云端JSON逐项一致。生成文件不手工修改；修改源数据后必须重建并运行 `npm run verify`。

年级记录由具名教材的 `gradeVerification` 控制。只有 `catalogue_verified` 且有阅读器定位值、原页页码或官方音轨位置的教材条目进入教材进度；`aligned_practice`表示依单元主题原创的内容，进度单独计数；候选、截断标题、未展开组及学校采用版本不会因生成脚本运行而自动升级为已核实。`bookIds` 可保留候选关联，不能单凭它计算年级掌握程度。

`scripts/curriculum.js`将九年覆盖清单与既有篇目证据关联，并校验36个册次、五年小学／四年初中的边界和来源。书目来源不产生新的`gradeMappings`；全册目录、知识项与版次未齐时，`fullCoverage`保持`false`。

内容 ID 区分同名诗、不同作者、不同首句与英语大小写；不能为合并方便而把 `May` 和 `may`、`Miss` 和 `miss` 合并。新增或修正教材映射要同时附证据及适用版本。

公开样本一上、一下、二上、三上封面标注审定 2024；样本版权页没有具体 ISBN 和印次，不能据网站的“2024版”称其为学校当前用书。古诗文的五四制目录与样本总计103个年级映射，包含三下6项、四年级16项和五年级35项；同名《绝句》另核对原页作者与首句。另有一至五年级字词与原创练习映射。来源区分`official_outline`、`public_sample`、`official_textbook`和`official_audio`；音频依据不推断纸本页码，已知版本差异保存在词项证据中。
