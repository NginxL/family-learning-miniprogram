## 提审资料

已提交审核版本：`1.0.0`。

版本说明：家庭学习计划与进度管理，支持每日新学／复习安排、按类型打卡、知识回顾、跨设备同步和家庭邀请；新增隐私与数据管理说明。

功能简介：帮助家长安排古诗文、英语及阅读等每日学习任务，记录孩子的学习进度，并与受邀家人同步。内容包含已注明来源和核验状态的基础知识资料。

审核操作说明：打开首页自动进入独立学习档案；在「今日」展开学习类型并打卡；在「计划」设置新学／复习、每天数量或手动添加；在「知识库」查看内容及来源；在「回顾」查看记录；在「家庭」编辑档案、查看隐私说明、生成邀请码。新账号可独立查看和使用主要功能，不提供真实家庭邀请码作为审核测试凭证。

首页路径：`pages/today/index`。隐私说明路径：`pages/privacy/index`。

后台隐私指引应按实际用途填写：微信账号标识用于身份识别和同步；成员称呼、孩子昵称及可选出生日期／年龄／年级用于档案展示；学习计划与完成记录用于安排、统计和回顾。联系信息使用运营者真实且可接收数据请求的方式，具体字段按微信后台表单填写。

首次备案从微信后台当前「去备案」入口办理。名称使用后台登记名称；主办者、负责人、证件及联系方式按真实账号主体填写。备案地区按主办者所在地及管局要求确定，不能根据教材地区或云服务器地域推定。用途说明可使用上面的功能简介，服务内容与前置审批选项需对照实际功能和表单要求确认。身份核验和短信核验由本人直接在官方页面完成。依据：[工信部备案通知](https://www.miit.gov.cn/jgsj/xgj/wjfb/art/2023/art_dd783a581c9644a4aee10afa582811db.html)、[备案流程解读](https://www.miit.gov.cn/zwgk/zcjd/art/2023/art_39b4f1acc36745b98478e0ec3e07128d.html)。

提交备案后须留意平台补件通知和工信部核验短信，按通知完成核验。代码审核已提交，可按后台通知处理审核反馈；程序内隐私说明不能代替后台配置。备案通过后，检查后台备案号及小程序更多资料中的展示，并在发布条件满足后完成发布。备案受理或通过均不代表代码审核通过，不重新购买云环境。

## 发布步骤与完成标准

1. 上传版本 `1.0.0`。上传只生成开发版本，不代表审核通过或正式上线。
2. 在微信公众平台的版本管理中选择该版本，核对既有名称、图标、服务类目、隐私指引与备案状态。服务类目必须符合实际功能，不选择需要但尚未取得资质的类目。
3. 填写功能和审核说明，提交审核。官方流程参考：[腾讯云发布后提审说明](https://docs.cloudbase.net/lowcode/practices/platform-guide/batch-deployapp)。
4. 审核通过后点击发布，以后台显示线上版本和正式二维码可访问为准；审核退回则按实际原因修正并重新提审。
5. 用另一微信账号扫描正式码，使用有效家庭邀请码加入；确认同一孩子和任务，打卡后另一端在重新打开或一个前台同步周期内出现更新。

正式版无需体验名单。家庭邀请码仍用于保护已有家庭记录。上传、审核中、审核通过、已发布是不同状态，只有最后一步完成才称为正式上线。
