## 提审资料

最近一次确认的审核版本：`1.1.0`，2026-10-19状态为「审核中」，当前最终结果待确认。

版本说明：新增统一任务详情与日期安排、明日计划及按星期自动使用模板；支持孩子提交照片或录音作业、家长确认；补充一至九年级语文英语学习资料，修正古诗文正文、背诵范围、英语义项词性及词形练习；保留历史学习记录和家庭云同步。

功能简介：帮助家长安排古诗文、英语及阅读等每日学习任务，记录孩子的学习进度，并与受邀家人同步。内容包含已注明来源和核验状态的基础知识资料。

审核操作说明：打开首页自动进入独立学习档案；点击「今日」学习卡进入任务详情，家长可完成整组；「明日计划」支持模板、按星期生成、删除及改期；「知识库」详情可查看内容和来源，并安排今日、明日或指定日期；「回顾」查看历史记录；「家庭」编辑档案、查看隐私说明、生成家长邀请码或孩子绑定码。验证孩子作业时，由审核者自己的两个微信账号分别作为家长和孩子，按 `docs/HOMEWORK.md` 完成绑定、拍照或录音、提交与家长确认。新账号无需额外账号密码即可独立使用主要功能，不提供真实家庭邀请码作为审核凭证。

首页路径：`pages/today/index`。隐私说明路径：`pages/privacy/index`。

后台隐私指引应按实际用途填写：微信账号标识用于身份识别和同步；成员称呼、孩子昵称及可选出生日期／年龄／年级用于档案展示；学习计划与完成记录用于安排、统计和回顾；用户主动提交的照片、录音、提交时间及家长反馈用于家庭作业检查。照片、麦克风／录音及按实际表单要求的摄像头声明见 `docs/HOMEWORK.md`，需与后台指引和补充文档同步。联系信息使用运营者真实且可接收数据请求的方式。测试账号选择「无需登录账号即可使用」，订单中心路径留空；本工具无交易订单。

首次备案从微信后台当前「去备案」入口办理。名称使用后台登记名称；主办者、负责人、证件及联系方式按真实账号主体填写。备案地区按主办者所在地及管局要求确定，不能根据教材地区或云服务器地域推定。用途说明可使用上面的功能简介，服务内容与前置审批选项需对照实际功能和表单要求确认。身份核验和短信核验由本人直接在官方页面完成。依据：[工信部备案通知](https://www.miit.gov.cn/jgsj/xgj/wjfb/art/2023/art_dd783a581c9644a4aee10afa582811db.html)、[备案流程解读](https://www.miit.gov.cn/zwgk/zcjd/art/2023/art_39b4f1acc36745b98478e0ec3e07128d.html)。

提交备案后须留意平台补件通知和工信部核验短信，按通知完成核验。新版本提交审核后按后台通知处理审核反馈；程序内隐私说明不能代替后台配置。备案通过后，检查后台备案号及小程序更多资料中的展示，并在发布条件满足后完成发布。备案受理或通过均不代表代码审核通过，不重新购买云环境。

## 发布步骤与完成标准

1. 备案已由账号持有人确认通过；新版云函数已部署，真实云端预览待真机验收。
2. 真机验收通过后，上传候选提交构建的新客户端，核对并填写其版本说明、服务类目和隐私指引，再提交审核。
3. 在版本管理中核对新版本的审核结果；`1.1.0`或更早版本的审核结论不代表候选新版已通过。
4. 新版审核通过并满足后台发布条件后，发布该已审核版本；以后台显示线上版本和正式二维码可访问为准。
5. 用另一微信账号扫描正式码，使用有效家庭邀请码加入；确认同一孩子和任务，打卡后另一端在重新打开或一个前台同步周期内出现更新。

正式版无需体验名单。家庭邀请码仍用于保护已有家庭记录。上传、审核中、审核通过、已发布是不同状态，只有最后一步完成才称为正式上线。
