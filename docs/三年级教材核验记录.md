## 内容和计量原则

三上7条背诵要求已由国家平台官方原页单独核实，见[要求页核验记录](三上背诵要求官方核验.md)。11处古诗文位置现已逐页核对国家平台官方原书，详见[位置核验记录](低年级古诗文位置官方核验.md)。三者分别记录来源与电子页码；国家平台正文页比印刷页多5，不能套用人教社阅读器的页码。

- 教材字表按原页逐字保存；蓝色多音字单独标识，不重复计作新字。人教社阅读器电子页比印刷页多6；补核园地篇目的国家平台原书多5，各映射保留对应来源。
- 阅读短文、中文释义、例句、问题和参考答案为原创学习辅助，按已核实主题编写，不标为教材原文。
- 教材字词和原创练习分别统计。原有内容 ID 保持稳定，同一个词跨册出现时共用学习记录。
- 英语三下旧版的版本标识在册次和条目来源中保留。核实到的单元不等于已覆盖全部教材知识；整册完成标记保持为否。
- 原书图片与配套音频仅作为本地核验材料，公开仓库保存来源、校验值及结构化学习条目。

语文三下《绝句》在电子页 8 核对作者杜甫及首句“迟日江山丽”，与已从二下原书核实的“两个黄鹂鸣翠柳”分开。三下写字表的“系”结合电子页 65 的系绳语境标为 `jì`；写字表未印注音部分和原创阅读的拼音属于学习辅助。三上第4单元英语标题为 **Water**，原书目录与配套音频一致。

三下补核依据[国家平台原书](https://basic.smartedu.cn/tchMaterial/detail?contentType=assets_document&contentId=bd1e1af7-f570-436d-afa4-f326691676f4&catalogType=tchMaterial&subCatalog=tchMaterial)：《忆江南》印刷14页、《守株待兔》16页、《滁州西涧》42页、《大林寺桃花》94页，电子页均加5。

三上第10单元同音项已由原书印刷89页确认为`flour`（面粉），与第3单元`flower`分列。原书`leaf (pl. leaves)`、`noodle (pl. noodles)`、`ask … for help`、`Very well.`保存在`textbookForm`，学习用词头与原ID保持稳定。10个单元词项数依次为14、17、19、18、17、12、14、18、15、15；第7单元从印刷88页延续至89页，不按一个单元统一填页码。纸本与音频证据分别保留。

三下牛津上海版试用本仍见于[2026春季上海用书通知](https://edu.sh.gov.cn/xxgk2_zdgz_jcjy_04/20260104/665a9f94e26543cf8a2be770a2d4af61.html)附件PDF第1页，且与新世纪版由学校选择。2025学年第二学期对应2026年春季，不能用来证明2026学年第二学期（2027年春季）新版要求；学校采用和完整纸本词表仍待确认。
