## 兼容性与验证

基线为九年级入库后的4,064个生成知识ID和4,072处年级／册次／单元关联，全部保留；新词带来1个知识ID和1处教材关联。教材来源更新不改计划、完成日志、掌握状态、同步队列或云接口格式。

`tests/full-catalog-review.test.js`固定基线ID与映射摘要，校验36册结构、纸本页码、旧版边界、词义、单向节选状态以及双客户端丢失响应后的重试。`tests/lower-editions-review.test.js`核对七册官方证据的年级学期、客户端旧版提示，以及4,109项原内容ID／标题／类型／学习时长和未改释义正文的固定摘要；旧完成快照和已学状态保持兼容。完整验证命令为`npm run build && npm run verify`，覆盖类型、生成一致性、包体、各年级、原生数据解压、页面和云接口。

七册版本复查阶段的2026-10-18验证通过：215项测试，类型检查、生成文件一致性和小程序包体检查均通过。七册版本复查只改变来源描述与展示信息，无学习记录迁移。

2026-10-17的全库验证中，全部4,109项内容各完成一次的档案为802,215字节，三个日期为909,049字节，均低于1 MiB保护线；这不代表允许无限积累自建内容或复习日期。

复核方法为全量结构与生成内容检查、已有逐册证据复查，以及重点原书页面复核；不宣称重新逐字校对36册全文。结构测试不能证明每项内容的教学适用性，双客户端模拟也不能代替两台真机验收。公开仓库仅保留结构化知识、原创辅助内容和证据链接，不包含整本教材、现代课文、扫描页或音频。
