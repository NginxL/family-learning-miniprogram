## 内容和计量原则

教材字表按原页顺序整理。蓝色多音字复习项单独记录，不计入新字总数；四上有 15 个复习位置，四下有 19 个。人教社阅读器电子页比印刷页多6；补核语文园地的国家平台原书多5，来源逐项区分。识字表注音按原书，写字表注音为结合语境整理的学习辅助。

英语四上以国家平台原书为主，Words to use印刷87–89页、电子94–96页共141项，目录电子5、7页另列5个未在卷末词表出现的主题词。四下仍以旧版官方音频为依据，保留轨道及校验值，不推断纸本全词表。

古诗文沿用公版原作，并核对作者、首句和册次；同名作品不能仅凭标题合并。现代阅读、例句、释义、提问及参考答案为原创学习辅助，按已核实单元主题编写，不标为教材课文或教材答案。

公开仓库保存来源、校验值和结构化学习条目，教材图片与出版社配套音频仅作本地核验材料。整册全量、整年级全量和学校采用确认均保持待确认状态。

词项数量按单元位置统计，跨单元复现共享已有内容ID。四年级共367项可选知识，其中241项为教材字词／古诗文，126项为原创练习。与先前年级重合的词和古诗不会复制一份新的学习记录。`hard`的“努力地／硬的”、`triangle`的“三角形／三角铁”合并已核实常用义，并在新单元来源中注明具体用义；不改写已有任务快照或完成记录，历史回顾中的内置词义随词库更新。`TV`与`television`归入同一学习条目，同单元来源去重，保留音频中的两个词项位置。

古诗文按原页核对作者、首句和范围。四上《凉州词》为王翰“葡萄美酒夜光杯”，四下《四时田园杂兴》为范成大“梅子金黄杏子肥”。《宿新市徐公店》采用所核教材的“树头新绿未成阴”，《雪梅》保留“阁笔”。《囊萤夜读》的唐代标签指《晋书》的编纂时代，依据[国家图书馆出版社书目](https://www.nlcpress.com/ProductView.aspx?Id=7128)；《王戎不取道旁李》标为刘义庆的南朝宋时期，依据[国家珍贵古籍名录](https://www.nlc.cn/migrated/pcab.nlc.cn/gjml/gjzggj/201412/P020141217510201045887.pdf)。不把故事人物的生活年代当作作品编纂时代。《精卫填海》注明《山海经·北山经》出处，准确成书年代保留待考。

英语音频经两轮转写对照，并对遗漏及同音歧义片段补核。四上第7单元 `week/weak` 结合 `44 Unit 7 Talking time.mp3` 中的每周饮食频率语境，收录为 `week`；已由原书词表进一步确认拼写为`week`。`keep tidy`等原书写法保存在`textbookForm`，学习词头仍沿用原ID，避免旧记录失联。

字表、目录主课古诗文及单元配套练习已整理，不等于整册知识全部完成。语文园地其他知识、现代作品、英语四下纸本全词表、新版下册、听说任务及学校采用版次仍有缺项。

语文四上补核《赠刘景文》《嫦娥》《黄鹤楼送孟浩然之广陵》《别董大》，四下补核《江畔独步寻花》（黄师塔前）、《蜂》《独坐敬亭山》，各保留国家平台原页定位。四下毛泽东《卜算子·咏梅》仅记录题名及位置，不转录全文。

## 软件验证

`tests/grade-four.test.js`核对两册字表的新字／复习／写字数量、唯一性、页码、古诗文身份、英文字词的音频证据、历史版次提示、全部单元可学习内容及语境拼音。两个隔离客户端验证安排、完成、同步、历史、已学标记和跨年级共用内容ID。

`npm run verify`同时检查类型、生成数据一致性、页面入口、微信主包大小及原有功能回归；软件通过不代替学校教材核验或真实手机验收。
