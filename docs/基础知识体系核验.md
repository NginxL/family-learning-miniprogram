# 基础知识体系与核验依据

核验日期：2026-10-18。范围为现有词义校正、语文记诵与文言理解、英语词汇运用与语法。七册旧版下册保留已有标识；学校实际采用版次仍待确认。

## 学习与记录

| 学习方向 | 可直接学习内容 | 定位方式 |
| --- | --- | --- |
| 背诵与默写 | 9组画面记忆、易错字、复述与理解性默写；低年级2组附静态拼音 | 按关联原作的已核年级、学期筛选 |
| 文言理解 | 51组词句说明、指代、古今异义、人物与表达；每组2道题及参考答案 | 关联小学文言入门及六至九年级原作，保留旧版册次 |
| 词汇运用 | 10组语境辨义、搭配、词族、构词、易混词形与词典使用 | 国家课标基础，不推定具体教材年级 |
| 英语语法 | 55组词类、句型、时态、语态、从句等讲解；每组2道题及参考答案 | 已核原书目录的条目关联六至九年级；其余明确待核实 |

知识库「筛选 → 学习方向」进入以上内容，可安排今日、明日或指定日期。「上海中考」的文言、语法入口也可直接进入相应练习。125组练习包含250道自编题及答案，不纳入已有230项语文阅读与练习、161篇英语短文的数量。

99处教材背诵要求涉及97项原作：每条保存具名版本、课后要求所在印刷页和电子页，分别标明背诵、默写和指定段落。例如九下2019版《送东阳马生序》要求在印刷56页／电子63页，范围为前两段，从“余幼时即嗜学”至“盖余之勤且艰若此”，不扩大为全文。未核要求的原作显示“范围待核实”；同一原作在其他册次没有核实要求时也单独标出。

原作和词卡另附可折叠的学习辅助：55篇文言原作的字词、句意、篇章与理解题；644项英语词卡的常用词形或数量表达、118组短语搭配及77组词族。讲解、参考答案可分别展开，查看不会新增学习记录。词头的教材映射不自动扩展为词族、例句也属于该册。逐册证据与剩余缺口见[背诵要求与逐篇辅助核验](背诵要求与逐篇辅助核验.md)。

原词条、原作及其学习ID保留。125组独立知识点练习使用独立ID，练习完成不反向认定原作已经背熟，也不把学过原作自动认定为掌握该知识点。独立练习由家长从知识库安排日期，保持已有每日模板的诗、词、句、文章数量含义。卡片内的辅助讲解不另建学习ID，不写入每日任务快照、同步写入队列或学习档案；旧任务详情按原内容ID读取当前辅助讲解，原正文与完成状态保留。

语文注释、英文例句和练习答案为自编教学辅助；不复制现代课文、教材整页或整套课后题。原书要求只记录背诵对象、范围与行为等事实。

保留原4,109项内容的ID、标题、类型、学习时长及全部原教材关联；其中96项通用英语释义更新为常用义和自编例句，其余正文不变。已保存的每日任务保留当时正文快照，日期、完成与掌握记录不迁移。按ID引用知识库的历史展示采用当前校正版释义；不增加学习次数。

## 验证范围

`tests/foundations.test.js`核对来源定位、部分背诵范围、无年级词项、知识练习独立记录、自动计划池排除、低年级拼音和双客户端重试；`tests/study-notes.test.js`另核对逐篇引文、词头与易混词形、部分册次要求、短语搜索、折叠操作无写入和旧任务的显示兼容。已有基线测试保留旧ID与教材关联摘要。构建时同步生成页面覆盖数量，避免固定数字与实际目录不一致。验证命令为`npm run build && npm run verify`。2026-10-18已通过234项测试及类型、生成一致性、包体检查，源码主包约1261 KiB；全部4,234项内容各完成一次的档案为829,099字节，三个日期为939,183字节，低于1 MiB保护线。模拟重试验证不能代替两台真机验收。
