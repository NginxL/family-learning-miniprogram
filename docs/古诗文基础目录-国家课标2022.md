# 古诗文基础目录（国家课标 2022）

核对日期：2026-10-12。依据教育部《义务教育语文课程标准（2022年版）》附录1，印刷页58–63。共135条：1–6年级75条，7–9年级60条。

[官方原文](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220420582344386456.pdf)。目录已对照原图核对。

**范围：这是国家课标推荐目录，不是上海中考全部篇目。** 对应公版原作已录入，正文逐字教材校对、现代注释、音频及上海各年级完整映射待确认；详见[知识库与年级核验](知识库与年级核验.md)。

“首句／选段标识”保留课标用于区分作品的文字，不作为完整背诵范围。同名作品保留多条；《论语》十二章等按课标合并计一条。
