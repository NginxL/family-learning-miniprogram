# 英语词典展示

## 页面与数据

英语单词的知识库详情、今日及明日任务详情共用词典模板：词头、音标、按词性分组的编号释义、教材用法、词形变化。列表显示音标和简短词义；朗读、安排日期、完成本组、学习笔记与来源入口沿用现有流程。

数据以2026-10-22版本计：2,748张词卡中，2,353张有来源明确的音标，2,581张显示至少一种明确词性。音标分别覆盖英式763张、美式2,319张、未标地区11张，统计可以重叠。395张暂无音标，主要是短语、完整表达和缩写；不拼接单词音标，也不把 `IT` 按代词 `it` 处理。未明确地区的记录只显示“音标”。

60个入门词补充了词性和适合入门学习的常见义项；279个原有基础词补充了具名词典支持的词性。原有教材单元义独立保留，相同词性、相同释义才去重，不因中文相同而合并名词和动词。所有释义都是学习用选义，不代表完整词典，也不推定为上海中考完整义项范围。

| 已确认结论 | 证据与实现 | 边界 |
|---|---|---|
| 音标来自精确词头记录 | `english-pronunciations.json`、`english-pronunciation-evidence.json`；固定源文件SHA-256、原行哈希及Wordnet词条ID | 来源定位通过校验，不等于每个读音均经过人工教学审定 |
| 18个词头单独核对 | `english-pronunciation-overrides.json`；Collins、Cambridge、Oxford具名词条 | `read/live/close/wind/lead/record`标出词性或时态；其他多音词的细分用法仍待逐词核实 |
| 入门义项与基础词性有独立证据 | `english-dictionary-core*.json`、`english-dictionary-basic-pos*.json` | 不从音标词典中的词性反推教学词性，不导入原通用词典全部专业义 |
| 教材归属和历史数据不变 | `scripts/word-dictionary.js`生成客户端独立数据；`word-entry.ts`仅生成视图 | 不写入共享知识库、任务快照、完成记录或同步队列 |

## 来源与许可

美式音标使用[CMU Pronouncing Dictionary 0.7b的IPA转换版](https://github.com/menelik3/cmudict-ipa/tree/73777bf317b25862482d805ee1feb1fe767d04e5)，转换作者Alexander Piperski。每个词头使用来源首个读音，不把语音识别词表中的其他弱读变体一起作为默认音标；已单独核对的多音词覆盖该默认值。CMU许可和作者署名随包保留。页面将`ɹ`、`ɫ`分别写作宽式音标`r`、`l`，不改变其余来源音素。

英式或未分地区的音标、部分入门义项使用[Open English Wordnet 2025](https://github.com/globalwordnet/english-wordnet/releases/tag/2025-edition)，保留CC BY 4.0及Princeton WordNet声明。英式标签只用于来源明确标为GB的记录。中文义项为简短改写，原英文定义、synset及哈希在证据文件中保存。

279个基础词的词性参考[ECDICT固定版本](https://github.com/skywind3000/ECDICT/tree/bc015ed2e24a7abef49fc6dbbb7fe32c1dadaf8b)，保留MIT许可。`a.`显示为`adj.`，`vt./vi.`可概括显示为`v.`；数词按教学分类标为`num.`。既有中文义项对照原词典行，不机械把一整行的多个意思都赋成同一种词性。

具名词典核对例：[read](https://www.collinsdictionary.com/dictionary/english/read)、[pinecone](https://dictionary.cambridge.org/us/dictionary/english/pinecone)、[unluckily](https://www.oxfordlearnersdictionaries.com/definition/english/unluckily)。全部链接在各词的“来源详情与说明”可复制；未确认项明确标注。

重新提取音标：

```bash
python3 scripts/import-english-pronunciations.py /path/to/cmudict-0.7b-ipa.txt /path/to/english-wordnet-2025.xml.gz
npm run build
npm run verify
```

提取脚本校验两个固定源文件哈希；原始下载文件和完整词典不进入小程序。压缩后音标、补充释义和已有词形的展示数据约104KiB。

## 兼容性与验证

旧任务详情保留保存时的`detail`；词典区读取当前知识库及客户端补充数据。遇到不同的历史文本时显示提示，并在来源区保留当时原文。查看词典不改变已完成、已掌握、复习次数、教材进度分母或历史记录。自建词卡只展示用户提供的文字，不按标题自动套用公共词典记录。

与`426edf0`的完整共享知识库比对：4,239项内容及顺序完全一致，云函数和共享学习逻辑没有改动。`npm run verify`通过332项测试、类型检查与212个JS/JSON文件检查，包体检查1682KiB。新增测试覆盖来源逐项匹配、词性分组、多音词、重复释义、大小写、自建词卡和旧任务快照。

微信WXML编译器生成的页面已在无界面浏览器核对320px及375px布局；这是源码渲染检查，不能代替微信真机验收。手机重点检查：知识库与今日词卡的音标、`book`名词／动词分组、`read`两种时态读音、朗读、安排日期及整组完成。

当前变更只需更新客户端测试预览，不需要修改云端协议或部署云函数。正式版仍需经过微信上传、审核与发布流程。
