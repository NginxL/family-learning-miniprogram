## 播放路径

手机先查找当前正文、语言和受支持音色的已保存文件。未命中时调用独立语音函数，优先读取腾讯已生成的云文件；没有文件且免费合成可用时生成并保存。腾讯免费到期、应用免费用量保护或供应商返回免费资源不可用时，只读已核对的豆包备用音频。

供应商明确返回免费资源不可用后，会记录本次免费期限内的停用状态，避免每次播放都重试同一失败合成。已保存的腾讯音频仍可读取。备用音频未生成或未通过核对时，显示“此内容的备用音频尚未备好”；不调用豆包付费API、不转后付费，也不在用户播放时自动启动豆包网页任务。

本机文件优先于网络，因此已缓存的豆包音频也能跨天、重启后直接播放。正文和音色没有变化时不重新生成。云端或本机文件损坏会报告错误或重新下载已存文件，不以此为由重复合成。较长文章按正文分段，免费资源在段间不可用时，后续段落可能使用不同的备用声音。

## 资源与核对

音频文件位于现有CloudBase私有存储`speech/library/v1/`，索引位于仅管理员可读写的`speechAssets`。公开教材内容的音频可供不同家庭复用，但播放仍校验微信身份、家庭和孩子访问权限。家庭自建内容不进入共享库，也不发送到豆包。客户端包及GitHub不包含MP3、云文件ID或凭证。

会员生成音频采用内置seed-audio，指定普通话或清晰自然英语、稍慢语速、只读正文、无音乐。该能力没有可锁定的真人音色或口音参数，因此不承诺严格英式发音或所有文件声音完全一致。集合的音色策略使用独立版本键；模型、语言、风格或处理参数改变时更换版本。

核对以小程序实际朗读段落为输入，逐项对照转写、时长、格式和文件摘要。存在疑似增读、漏读或发音疑点的文件保留为待核对，不上传为可播放状态。ASR同音字不能证明具体用字，古诗文多音字仍需结合教材和人工试听；不得把自动转写写成真人审听。

音频统一为MP3、16kHz、单声道、32kbps；单段不超过512KiB。上传后回读逐字节核对，成功后才将索引设为ready。上传失败的记录保留实际字节预留，重试只上传原文件，不重新生成。

## 存储与额度保护

腾讯生成的家庭音频和导入的公开备用音频共用128MiB应用存储保护；导入按实际文件字节数计数，重复导入不重复占用。另设每日128MiB下载保护，手机文件命中不请求云端。128MiB是应用限制，不是腾讯套餐的赠送空间。云存储、函数、数据库及传输仍消耗已有资源点。

容量按每批实测文件大小复核。首批实际占用约581KiB，仅占128MiB保护上限的0.44%，因此保留现有上限，没有扩容。只有现有套餐余量支持且不会开启额外计费时才考虑提高保护上限。套餐资源耗尽或到期会影响云端读取，手机已经保存的音频仍可播放。导入命令必须提供15分钟内取得的预付费套餐信息，验证正常、未到期且超限付费关闭。

## 操作与维护

```bash
# 按正文和音色去重，并跳过已存音频和待试听文件
node scripts/speech-library.js queue tmp/audio-queue.json \
  --exclude docs/audio-batches/2026-10-22.json

# 校验带核对记录的音频批次，不访问云端
node scripts/speech-library.js validate tmp/audio-batch/manifest.json

# 已有临时管理凭证与套餐查询文件只存操作者私有目录
node scripts/import-speech-library.js \
  --manifest tmp/audio-batch/manifest.json \
  --session tmp/private-session.json \
  --billing tmp/current-billing.json \
  --receipt tmp/import-receipt.json
```

批次清单包含准确正文、正文摘要、音色版本、时长、字节数、音频摘要、核对方法和时间。`validateBatch`会重新对照当前公开知识库，拒绝正文过时、自建文字、未核对文件、错误摘要和路径越界。凭证不得进入Git或小程序。

`queue`的`items`仅含待生成段落，`reviewPending`单列已取得但未通过核对的文件。可重复指定`--exclude`合并多批清单；正文或音色改变产生新键，旧清单不会误排除新版。已存文件损坏先尝试从保存的原文件恢复，不因批次重跑重复消耗合成额度。

测试函数入口为`speech-index.main`，仅在原有`SPEECH_STORAGE_INCLUDED_ONLY=true`及`SPEECH_LIBRARY_ENABLED=true`下启用此方案。只部署`familySpeechPreview`，保留原函数密钥和免费期限；不改审核中1.3.0的路由或包。正式发布需固定客户端、语音函数、批次清单及隐私说明，并做手机播放和多账号权限验收。
