## 播放路径

手机先查找当前正文、语言和受支持音色的已保存文件。未命中时调用独立语音函数，优先读取腾讯已生成的云文件；没有文件且免费合成可用时生成并保存。腾讯免费到期、应用免费用量保护或供应商返回免费资源不可用时，只读已核对的豆包备用音频。

供应商明确返回免费资源不可用后，会记录本次免费期限内的停用状态，避免每次播放都重试同一失败合成。已保存的腾讯音频仍可读取。备用音频未生成或未通过核对时，显示“此内容的备用音频尚未备好”；不调用豆包付费API、不转后付费，也不在用户播放时自动启动豆包网页任务。

本机文件优先于网络，因此已缓存的豆包音频也能跨天、重启后直接播放。正文和音色没有变化时不重新生成。云端或本机文件损坏会报告错误或重新下载已存文件，不以此为由重复合成。较长文章按正文分段，免费资源在段间不可用时，后续段落可能使用不同的备用声音。

## 资源与核对

音频文件位于现有CloudBase私有存储`speech/library/v1/`，索引位于仅管理员可读写的`speechAssets`。公开教材内容的音频可供不同家庭复用，但播放仍校验微信身份、家庭和孩子访问权限。家庭自建内容不进入共享库，也不发送到豆包。客户端包及GitHub不包含MP3、云文件ID或凭证。

会员生成音频采用内置seed-audio，指定普通话或清晰自然英语、稍慢语速、只读正文、无音乐。用户已实际试听并认可英式、美式参考样音；后续分别沿用对应口音提示词。该能力没有可锁定口音或真人音色的参数，因此样音认可不代表每条录音都已经真人审听，也不保证所有文件声音完全一致。词句转写核对与口音试听分别记录，疑似错读不进入可播放状态。

英语播放提供“通用朗读、英式发音、美式发音”选择，偏好只保存在手机。现有通用录音保留原v1音色键，英美各用独立v2键，内存及本地缓存隔离；不能根据Mum/Mom转写差异把旧录音改标为某种口音。用户已接受美式Mom称呼，适用于通用录音，以及生成请求明确指定已认可美式样音的句子和短文；英式录音和同时列出mum、mom两个词项的词卡仍逐项核对。明确选择某种口音时只读取该组已核对音频，未就绪会提示，不以其他声音替代。通用播放在腾讯免费不可用且没有旧通用文件时，可依次复用已有英式、美式文件，避免为相同文字再做第三份录音。

核对以小程序实际朗读段落为输入，逐项对照转写、时长、格式和文件摘要。存在疑似增读、漏读或发音疑点的文件保留为待核对，不上传为可播放状态。ASR同音字不能证明具体用字，古诗文多音字仍需结合教材和人工试听；不得把自动转写写成真人审听。

疑难片段可增加本机Qwen3-ASR-1.7B独立转写，输入只有录音，不提供原文、热词或语言提示。采用前先验证截短诗句不会补齐缺失下文、静音不会产生正文；核对结果绑定音频摘要和模型版本。对多音字、声调及指定英美口音存在明显转写分歧的片段，第三份文字一致也不自动放行，仍保留待试听状态。

用户的读音确认或否定均绑定具体录音摘要和核对范围。2026-10-23用户确认《送元二使安西》的“二”和《题临安邸》的“直”读音正确，这两段结合全文独立转写通过核对；《生查子》的“查”、“法家拂士”的“拂”、《记承天寺夜游》的“解衣”及《如梦令》的“兴尽”被用户确认错读，相应4份录音明确拒绝入库。局部读音确认不等于整段真人审听，已被否定的录音不能因自动转写文字一致而放行。

音频统一为MP3、16kHz、单声道、32kbps；单段不超过512KiB。上传后回读逐字节核对，成功后才将索引设为ready。上传失败的记录保留实际字节预留，重试只上传原文件，不重新生成。

分组录音先按实际静音间隔切分，再逐段转写核对。相同文章中完整出现的句子可从原录音切出，仍单独校对，不再次合成。拼音对齐仅用于定位切分边界，不能作为通过核对的依据。数词的数字转写、同词的英美拼写和已逐项确认的同音单词可记为转写差异；诗题中的辨识括注、词典的`pl.`与`AmE`标记可以不读，但题名、作者、正文和实际词项须完整保留。所有差异及核对方法保存在清单中。

## 存储与额度保护

腾讯生成的家庭音频和导入的公开备用音频共用256MiB应用存储保护；导入按实际文件字节数计数，重复导入不重复占用。另设每日256MiB下载保护，供预计约200MiB的全库导入回读及正常播放共同使用，保留现有当日累计计数。手机文件命中不请求云端。这些数值是应用保护限制，不是腾讯套餐的赠送空间；手机本地缓存保护仍为128MiB。云存储、函数、数据库及传输仍消耗已有资源点。

容量按每批实测文件大小复核。按已核对的32kbps文件估算，中文、英美两版与既有通用录音合计约200MiB，应用存储保护调整为256MiB。2026-10-23 11:33查询本周期已用8,016.33 / 40,000资源点，按量用量为0，超限付费关闭；没有购买或调整腾讯云套餐。账单可能延迟，估算也不是完成后的实际容量，仍以逐批字节计数限制导入。套餐资源耗尽或到期会影响云端读取，手机已经保存的音频仍可播放。导入命令必须提供15分钟内取得的预付费套餐信息，验证正常、未到期且超限付费关闭。

## 操作与维护

```bash
# 按正文和音色去重，并跳过已存音频和待试听文件
node scripts/speech-library.js queue tmp/audio-queue.json \
  --exclude docs/audio-batches/2026-10-22.json

# 校验带核对记录的音频批次，不访问云端
node scripts/speech-library.js validate tmp/audio-batch/manifest.json

# 已有临时管理凭证与套餐查询文件只存操作者私有目录
node scripts/import-speech-library.js \
  --manifest tmp/audio-batch/manifest.json \
  --session tmp/private-session.json \
  --billing tmp/current-billing.json \
  --receipt tmp/import-receipt.json \
  --concurrency 3
```

管理导入默认逐份执行，可用`--concurrency`设置1至4份并行；每份仍单独预留实际容量、上传并回读校验。任一份失败后停止安排新上传，等待已开始的操作结束并记录成功结果，随后报错；重试沿用已存文件。此设置只影响本机管理工具，不改变小程序或云函数运行逻辑。

批次清单包含准确正文、正文摘要、音色版本、时长、字节数、音频摘要、核对方法和时间。`validateBatch`会重新对照当前公开知识库，拒绝正文过时、自建文字、未核对文件、错误摘要和路径越界。凭证不得进入Git或小程序。

`queue`的`items`仅含尚无生成结果记录的段落，`reviewPending`单列已取得但未通过核对的文件，以及远端已报告生成但文件尚未取回的结果；清单的逐条说明区分两种状态。待接收文件先恢复原生成结果，不重复合成。可重复指定`--exclude`合并多批清单；正文或音色改变产生新键，旧清单不会误排除新版。已存文件损坏先尝试从保存的原文件恢复，不因批次重跑重复消耗合成额度。

核对失败的片段经用户单独授权可补录一次；每个目标键记录该轮尝试，不因失败自动再试。2026-10-23获准的一次补录仅含801条未通过核对或无有效原结果的主音频，另100条句子从对应短文切分；7,956条已通过资源均被排除。补录沿用现有会员额度和英美样音标准，结果仍须通过逐项核对及云端回读后才可播放。

测试函数入口为`speech-index.main`，仅在原有`SPEECH_STORAGE_INCLUDED_ONLY=true`及`SPEECH_LIBRARY_ENABLED=true`下启用此方案。只部署`familySpeechPreview`，保留原函数密钥和免费期限；不改审核中1.3.0的路由或包。正式发布需固定客户端、语音函数、批次清单及隐私说明，并做手机播放和多账号权限验收。
