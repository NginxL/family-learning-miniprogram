## 年级分类规则

九年范围分为小学1–5年级、初中6–9年级；每年级语文、英语各有上下册，共36个学科册次。语文核验范围包含识字写字与拼音、古诗文、现代文与整本书阅读、表达习作及口语交际；英语包含语音、词汇短语、语法句型、听说、阅读与书面表达。数学不在当前知识库建设范围。

逐册清单将出版书目信息与实际入库知识分开：`references`只记录已观察的官方标题、链接和学年；`contentBookId`关联具名内容样本，不能证明与官方书目版次完全一致；`verifiedCount`统计可用内容，拆分为`textbookCount`（教材字词、古诗）和`practiceCount`（单元原创练习）；`availableUnits`仅表示已有配套内容的单元数。18册语文书名核验不代表18册课文全部核验，36个册次建档也不提高知识进度分母。

英语上册依据2026学年第一学期资源表；当前可核对的下册表为2025学年第二学期，部分年级列有牛津上海版、新世纪版试用本。后者以`historical_resource_listing`保留候选，不自动选择学校版本，也不认定为2026学年第二学期用书。出版方网站同时提供六三制沪教版资源，不能凭“沪教版”三个字归入上海五四制。

国家课标的 **1–6／7–9 年段**与上海的**五四学制年级**分别保存；国家英语二级词汇不是一年级、二年级或上海小学的完整词表。上海六年级属于初中预备年级。

年级归属须有具名教材、学制、版本、年级／册次、可追溯位置及核验状态。已读取的目录位置保留为 `outlineDestination`，它是阅读器定位值，未转换成未经核实的印刷页码。学校是否采用该版次另标待确认；目录位置核实也不等于正文逐字校对完成。

## 知识进度的含义

- **年龄、在读年级**由家长填写；有生日时按上海日期自动计算年龄，旧年龄保留填写日期，不自动按年龄推算年级或水平。
- **学过**要求至少有一次完成记录；**已掌握**要求家长确认，重复复习不重复计知识项。撤销最后一次完成会同时撤销掌握。
- **教材年级进度**只统计已核实的教材对应条目，原创单元练习另列，不计入教材条目分母；识字写字按单元组计数，不把一组字等同于一首诗的学习量；“已涉及六年级部分篇目”不代表达到六年级综合水平。
- **家长标注年级**可记录一年级孩子学习三年级内容的情况，与教材证据统计分别展示。未知年级内容保留在回顾和科目累计中。

知识库按当前孩子的已确认完成记录显示「已学过／已掌握」，展开可见最近学习日期及完成天数；可筛选已学和未学。仅加入计划、浏览或待批改作业不计入已学。断网缓存单独提示，撤销最后一次完成后移除标记。

尚无完整的逐年级、逐科目分母，因此不输出“已经学完小学”“达到三年级”或整年级百分比。当前每个年级的 `fullGradeComplete` 均为 `false`。

## 来源与正文选择

135 条课标索引保留原始标题与选段标识。正文通过作者、作品、首句、组内序号选择；不将《绝句》《凉州词》《悯农》《四时田园杂兴》的同名作品合并。十二章《论语》、三则《孟子》仍各计一个课标条目。

公版原作转录主要参考 [aopao/chinese-gushiwen 固定版本](https://github.com/aopao/chinese-gushiwen/tree/c2345d0abf2404b8b3601e4afc2e8fd12f90d6c8)，保留条目 ID。仓库未提供整体许可，仅使用著作权保护期已届满的古代原作，不复制该库现代注释、翻译、配音或代码。《虽有嘉肴》《伯牙鼓琴》《书戴嵩画牛》等单列补充文献来源，见条目 `textSources`／`sourceUrl`。

正文仍存在需要教材定版的异文，如《闻王昌龄左迁龙标遥有此寄》的“随风／随君”、部分全文与课本节选的差异。当前正文属于原作阅读参考，不能据此自动进行逐字默写判错。《古朗月行》《赋得古原草送别》等不能把全文直接视作学校必背段落。

英语的 `Miss/miss`、`May/may` 分别建项，不能按小写合并。基础词常用义区分了 `can` 的情态义和名词义、`may` 与月份、`the` 的冠词作用等。英美拼写、复数和同义缩略形式保留为同一课标词条组，1,600 是组数，不是所有拼写变体的数量。

一上、一下、二上、三上的公开样本仅用于本地核验。样本封面标注“审定2024”，版权页的 ISBN、印次留空，不能自行补写为具体版次。样本中的《古朗月行》只选前四句，以独立内容 ID 保存并关联完整原作；自动“全新”安排按作品去重。《画》在所核样本中未署作者，保留“教材未署作者”。

完整现代课本、录音和注释没有打包或上传公开仓库；小程序的完整课本入口仍通过官方平台登录阅读。源代码公开与第三方教材的分发权限分别管理。

## 逐册核验的完成标准

| 层次 | 达到该层次所需证据 |
|---|---|
| 教材版本确认 | 封面、版权页、ISBN／审核信息、学制、版次、学年，及学校实际选用证据 |
| 年级目录确认 | 全册目录、课外诵读组内篇目、语文园地／日积月累及单元词表逐页核对 |
| 学习正文确认 | 作者、完整标题、正文、异体字／异文、节选边界与教材逐字一致；现代材料有可用范围依据 |
| 整年级覆盖确认 | 上下册及对应科目清单齐全，缺项为零；范围有版本号与复核记录 |

代码通过结构和行为测试，只能证明软件遵守数据规则，不能代替教材内容核验。英语一二年级部分卷末纸本、三上纸本及三至五年级新版下册，四五下语文新版、各年级完整能力与逐课知识、上海中考全量清单及具体学校版次仍待核验。
