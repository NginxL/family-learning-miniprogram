## 证据范围与兼容性

7条背诵要求使用官方来源，要求类型、全文范围和页码保持原值；不能据此推定上海当届中考完整必背范围。

背诵要求页与篇目正文页分别保存证据。11条篇目位置映射仍保留样本来源；《夜书所见》《饮湖上初晴后雨》《司马光》的官方正文页已见于上述三页，其余8处正文位置待单独核对。进度页的“第三方样本”数量统计的是位置映射，不代表背诵要求尚未核实。

同一册的两类来源允许不同，但独立的背诵来源必须匹配已核页图记录中的册次、年级学期、内容ID、网址和页码。来源详情分别提供正文位置与背诵要求的依据链接。

内容ID、教材关联、任务快照与学习记录保持不变。`1.1.0`审核包和线上云函数维持原版本，下一版本同步发布状态见[发布清单](RELEASE.md#下一版本的客户端与云端一致性)。

`npm run verify`通过：类型检查、172个JS/JSON文件检查、279项测试全部通过；小程序包体1427 KiB。构建校验拒绝未登记的官方链接和不匹配的要求页码，界面测试核对两类来源分别显示。
