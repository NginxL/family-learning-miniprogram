# 模板范围与缺额

## 规则与证据

| 场景 | 当前源码行为 | 验证依据 |
|---|---|---|
| 配了数量但生成不足 | 数量是目标；全新任务只从所选范围中选择从未安排过的内容，内容不足时保留缺额，不自动跨范围或改成复习 | `src/shared/learning.ts`、`tests/learning.test.js` |
| 范围不易察觉 | 数量旁直接显示并可修改「全新／复习」和内容范围；明日预览展示生效模板的数量摘要 | `miniprogram/pages/plans/index.wxml`、`tests/templates.test.js` |
| 旧云端缺额文案不够明确 | 客户端根据当天保存的生成规则展示范围、目标和实际数量；不使用尚未保存的模板草稿推断 | `src/miniprogram/lib/page.ts`、`tests/templates.test.js` |
| 补了内容却仍无法补齐今日 | 明确应用今日且保存相同规则时，在原范围中尝试追加缺额；目标扣除当天主动删除的自动任务槽位 | `tests/template-refill.test.js` |
| 知识库闪过数学、其他 | 知识库从初始数据到每次渲染都只接收自己的分类；其他页面仍可读取旧分类记录 | `tests/library-filters.test.js` |

「亲子入门」是少量入门材料，当前包含12首古诗文、12条英语句子和6项语文阅读。全新模式排除曾经安排过的内容，包括尚未完成的任务。切换到五四制等更大范围会增加候选内容，该范围覆盖多个年级；它不等于按孩子在读年级自动筛选。查看范围内全部内容的数量也不等于剩余可新学数量。

今日可以按科目筛选；「英语」下只显示英文相关组，切回「全部」可看语文阅读。明日计划始终显示全部学习类型。缺额说明提供模板入口，家长可以显式调整范围；不会自动重置原设置。

## 今日重排与兼容

只有携带`applyToday: true`且影响今日生效模板的请求会调整当天安排。规则变化时沿用原有定向重排；规则未变且数量不足时仅追加可选的新自动任务。模板编辑模式跳过普通日计划的全局去重和手动计划注入，避免保存模板时清理旧的重复快照或意外补入手动任务。

已完成任务、曾被操作过的任务、手动安排、其他孩子的任务和已提交作业的组均保留。主动删除槽位不自动补回。新学仍排除曾安排内容，复习仍只选择已完成内容，未来指定日期的内容继续保留。历史内容ID与已有学习记录无需迁移；旧客户端没有`applyToday`时保持原有行为。
