# 导入、部署与家庭试用

## 工程和账号

按 README 安装依赖、生成配置并打开微信开发者工具。`project.config.json`、`project.private.config.json`、`miniprogram/config.js` 为本地文件，均已忽略。

AppID 入口：[微信公众平台](https://mp.weixin.qq.com/) → 选择小程序 → 开发管理 → 开发设置 → 开发者 ID。AppID 可导入工程，不能证明认证、备案、成员权限或云环境状态。

在已登录的微信开发者工具中，用真实 AppID 打开工程，进入「云开发」。选择已有且属于该小程序的环境，或确认套餐后新建环境，复制环境 ID：

```sh
npm run configure -- --appid wxYOUR_APP_ID --env YOUR_CLOUDBASE_ENV_ID
```

占位符换成实际编号。选择支持文档型数据库的环境；本版不依赖 SQL、容器、静态网站或自购服务器。套餐与免费期限以[官方价格](https://cloud.tencent.com.cn/document/product/876/127357)和控制台为准，付费前核对金额及续费设置。

## 数据库与函数

创建八个空集合：`profiles`、`families`、`invites`、`days`、`receipts`、`learning`、`homeworks`、`attachments`。每个集合使用自定义安全规则：

```json
{ "read": false, "write": false }
```

`cloud/database.rules.json` 是逐集合清单，不会随源码自动生效。云存储同样设置自定义规则 `cloud/storage.rules.json`，禁止客户端直接读写；仅云函数检查成员身份后处理附件。全部配置完成后再部署云函数。所有访问按主键，无需额外复合索引。

```sh
npm ci --ignore-scripts
npm ci --prefix cloudfunctions/familyApi --ignore-scripts
npm run build
npm run verify
npm audit --prefix cloudfunctions/familyApi --omit=dev
```

知识库、学习记录、云函数、页面及同步队列的源码位于 `src/`，以上构建会生成原路径下的 JS；不要直接修改生成文件。页面模板和样式仍位于 `miniprogram/`。类型依赖仅安装在仓库根目录，不加入云函数生产依赖。当前 TS 迁移的兼容范围与验证见[构建约定](TYPESCRIPT.md)。执行构建与测试不会上传小程序或部署云函数。

右键 `cloudfunctions/familyApi`，上传并部署（云端安装依赖），保留函数名 `familyApi`。选择控制台支持的 Node.js 20 或更高运行时，初期超时 20 秒、内存 256 MB。保留锁文件和覆盖配置；确认部署环境遵循这些依赖版本，否则用本地 `npm ci` 后连依赖上传的方式。

通过小程序调用，不配置公开 HTTP 触发器。控制台测试没有微信 `OPENID` 时返回 `UNAUTHENTICATED`，属于正常拒绝访问。

首次通过小程序打开时，服务端按微信身份自动准备「我的家庭」及通用孩子档案：昵称「孩子」、6 岁、一年级、无生日。正式发布入口不再读取 `DEFAULT_CHILD_*` 环境变量，防止把部署者的个人信息复制给其他账号。已有数据库档案和学习记录保持不变；真实昵称、生日由家庭创建者在「家庭」页编辑，生日优先用于自动计算周岁。个人信息不提交公开仓库。

从旧版升级角色与作业功能时，先新增并保护 `homeworks`、`attachments` 集合，再部署兼容旧家长接口的 `familyApi`。云函数代码更新不改变已审核的小程序包。保存现有函数代码以便回滚；若已有孩子成员，不能回滚到不识别孩子角色的旧服务，否则会失去角色限制。微信后台隐私声明与绑定流程见[角色与作业](HOMEWORK.md)。

计划调整接口复用现有集合，无需迁移历史数据或新增索引。`days` 的可选 `omitted`、`planRevision` 字段及 `receipts` 的 `planning` 回执用于日期内排除、并发校验和幂等重试；旧完成回执的 `task` 字段保持兼容。先部署云函数，再使用带删除／改期入口的预览包。已有计划调整数据后，服务端回滚版本必须识别这些字段，否则被删除的自动任务可能重新生成；小程序包可单独回退。

每日模板同样复用现有集合：`families.templateSets` 是按孩子保存的可选字段，`receipts.template` 保存重试回执。旧数据读取时显示默认模板，首次修改时才写入；启用规则同时镜像到旧 `autoPlans`，旧客户端仍可读取和编辑。先部署兼容服务，再使用模板预览包，无需重建家庭或历史记录。使用模板后，服务端回滚版本须支持 `templateSets` 与旧接口联动，避免旧 `autoPlans` 和模板规则分叉；数据库及函数代码应配套备份。

按星期使用在模板集合中增加可选 `weeklySchedule`，未配置时保持每天相同。`saveTemplateSchedule` 与模板编辑共用版本和幂等回执；旧客户端只能调整默认模板，不会清除星期配置。先部署支持按目标日期选择模板的服务，再使用新版预览。服务端回滚前应先通过支持该字段的版本切回每天相同，否则旧服务会忽略星期安排；当前云函数更新不替换已审核的小程序包。

## 两个账号验收

| 操作 | 预期 |
|---|---|
| 家长生成孩子绑定码；孩子独立微信加入、提交照片或录音 | 孩子只见自身档案，无完成按钮；提交后待确认，家长可查看并确认或退回 |
| A 首次进入默认家庭，在「家庭 → 家人管理」生成邀请码；B 使用邀请码加入并确认切换 | 两端同一孩子和任务；B 原默认家庭记录保留，退出后恢复 |
| A 完成任务；B 前台等待或重新打开 | 一个轮询周期内或重新打开后看到更新 |
| A 断网打卡并退出，恢复网络再开 | 队列恢复、只记一次 |
| 两端离线修改同一项，先后联网 | 冲突提示，不静默覆盖 |
| A 移除 B，B 再请求 | 读写被拒绝、联网清理缓存 |
| 暂停计划、切换新日期和历史 | 新日期采用当前计划，历史快照不变 |
| 分别设置全新／复习和各类数量 | 全新不重复安排旧内容；复习只选择已完成内容；不足时显示缺额 |
| A 新建并启用模板，B 查看并修改同一模板 | 次日按启用模板生成；今日已生成任务、已完成记录和单次调整保留；同时修改时提示冲突，不覆盖未保存草稿 |
| A 配置周一至周五和周末模板，B 查看明日计划 | 按学习日期的星期选择；修改星期安排、编辑被引用模板后同步更新预览；今日及完成历史保持不变 |
| 知识库加入今日、完成、确认掌握 | 今日、回顾和知识进度使用同一条内容记录，两端同步 |
| 修改生日与在读年级；另一端读取 | 生日同步，年龄按上海日期重算；未填生日时兼容手填年龄，跨年级学习不改变在读年级 |

覆盖 iPhone、Android、慢网、存储失败和云函数超时。确认集合客户端直读／直写均拒绝，再添加真实家庭数据。

## 试用与维护

上传后可在微信公众平台设置体验版，供已添加的体验成员测试。体验成员是个人微信账号，无需家人注册公众号。正式版通过审核并发布后，用户直接扫码打开，不需要加入体验名单；访问已有家庭仍需应用内家庭邀请码。发布资料与状态见[正式发布](RELEASE.md)。

从控制台导出八个集合及私有作业文件，并恢复到单独测试环境验证。`receipts`、`days` 和 `learning` 一起备份；学习记录禁止进入公开仓库。删除家庭数据时由管理员按核准家庭 ID 清除八个集合中对应数据及私有附件，设备联网后撤销缓存。

从 v0.1 升级时，先创建并保护 `learning` 集合，再同时部署新的云函数与小程序。旧固定计划继续按每天执行；读取旧日期时把该日完成记录写入知识档案，不凭空补造任务。旧历史未读取前，新知识档案可能尚未包含那些日期，跨日期汇总需要逐日补索引或经管理员验证的迁移。

管理操作不进入离线重放队列，网络失败先刷新确认结果再重试。邀请码仅生成时显示，遗失可以重新生成。自助备份、删除与管理员转让待实现。
