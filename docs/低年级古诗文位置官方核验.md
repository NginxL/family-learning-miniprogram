## 构建与兼容边界

官方来源按“册次ID＋内容ID”逐项使用，构建时核对年级学期、单元、篇名、印刷页、电子页及页图凭据。无独立证据的关联仍使用原样本来源；不会把整册字表或练习一并升级。

来源字段用于知识库、来源详情与进度页的证据标注。学习内容ID、正文、背诵要求、任务快照和完成记录保持不变。新版预览使用当前客户端；1.1.0审核包与线上云端保持原版本，客户端与云函数同步发布见[发布清单](RELEASE.md#下一版本的客户端与云端一致性)。

## 验证结果

`npm run build && npm run verify`通过：类型检查、176个JS／JSON文件、生成产物一致性及285项测试，主包约1428 KiB。

与基线`6fba746`逐项比较：4,190个知识内容ID及4,234个总目录ID、顺序、全部正文和138条背诵要求不变。变化仅在31篇原作及2项关联原创练习的来源字段；所有任务快照与数值进度保持一致。31篇的已学次数、掌握状态和只读来源展示有独立回归测试。

第三方来源关联由286条降为253条（含关联练习），不等同于253篇古诗。进度页仅有第三方位置依据的内容数：一年级16／151、二年级53／120、三年级0／252；分母与已学、掌握统计不变。

基于`3545c8b`的1.1.0云函数在本地内存环境验证当前客户端，旧任务、离线重试、丢失响应、另一位家长同步和掌握状态均通过。该验证没有访问或更新线上云端，不替代真机验收。
