# 家长与孩子：绑定及作业

## 使用流程

1. 家庭创建者打开「家庭」，在孩子档案下点击「绑定这个孩子的微信」，确认监护人用途说明，生成孩子绑定码。
2. 孩子使用自己的微信打开小程序，在「家庭 → 家人管理」输入绑定码及称呼。绑定码24小时有效、仅可使用一次；生成任何新邀请码都会使旧码失效。
3. 孩子点击今日卡片查看内容，再点「提交作业」，拍照、选择照片或录音。提交后显示「待家长确认」，学习完成数保持不变。
4. 家长打开同一任务详情，点「查看孩子提交的作业」，查看附件后确认整组完成，或附上反馈退回。孩子可重新提交。

家长仍可直接完成／撤销整组。孩子账号没有切换成家长的入口；绑定错误由家庭创建者移除成员后，重新生成对应身份的邀请码。普通家人邀请码对应家长身份，请勿交给孩子。开发预览仍需微信平台赋予对应微信账号体验／开发权限；应用内绑定不能替代平台权限。

## 权限与兼容

| 身份 | 可操作范围 |
|---|---|
| 家庭创建者 `owner` | 家长全部操作；管理成员、孩子档案及邀请码 |
| 家长 `guardian` | 学习计划、完成／撤销、掌握确认、查看和审核本家庭作业 |
| 孩子 `child` | 绑定档案的任务、历史、进度和附件；提交作业。不能修改计划或完成状态，不能访问其他孩子 |

身份由微信上下文和服务端成员记录确定，客户端不能自报角色。`createInvite` 新增可选 `role`、`childId`、`guardianConsent`；旧邀请码缺省为家长。原有集合、内容ID、任务完成接口和缓存格式保留；角色或绑定档案变更时清除旧缓存和待同步队列。

作业按家庭、孩子、日期、学习类型分组。`submitHomework` 只保存提交状态；`reviewHomework` 用版本校验，在一个事务中确认本组任务和学习记录。家长修改过任务后，旧提交不能覆盖新状态；需退回让孩子重新提交。家长原有整组打卡仍按任务逐项同步，全组完成时同步标记对应作业已确认。

## 附件与数据维护

录音使用微信原生录音管理器，不使用语音合成、语音识别或自动评分。每次提交1–3份JPG／PNG照片或MP3录音；客户端先压缩照片，单份上限512KiB，录音最长60秒。服务端再次校验格式、大小、归属和任务范围。上传编号与提交编号支持响应丢失后的重试。

云存储和八个数据库集合禁止客户端直接读写。附件由云函数上传、读取并返回内容；不返回云文件ID或公开URL。读取时再次检查成员与档案权限，孩子只能访问自身当前提交的附件。微信云环境管理员仍有维护权限。

每家庭附件累计上限100MiB。失败上传的预留额度、重新提交前的旧附件及已上传但未提交的附件暂由管理员清理，不会自动回收；达到上限后停止接收新附件。管理员需按家庭核实待删除记录、删除对应私有文件和附件记录，再重算 `families.homeworkBytes`，同时处理引用这些附件的 `homeworks`，避免留下失效引用。删除与导出入口见小程序「隐私与数据管理」。附件不得进入公开仓库或公开截图。

提交要求联网，未提交草稿只在当前作业页保留，离开页面可能丢失。切出页面停止录音和播放；下载的预览文件在页面卸载时清理。后台、锁屏不保证刷新，家长和孩子可主动点击刷新。

## 微信后台隐私配置

录音和选取照片前调用 `wx.requirePrivacyAuthorize`，麦克风另经 `scope.record` 授权。管理员还需在微信公众平台隐私保护指引中如实声明对应信息类型；仅在小程序内显示说明不能替代平台配置。[腾讯云官方适配说明](https://cloud.tencent.com/document/product/1301/97930)

在后台按实际可选名称补充以下用途（保留原有账号、家庭档案、学习记录条目）：

| 信息／权限 | 用途文字 |
|---|---|
| 选中的照片或视频信息（本工具仅使用照片） | 在用户主动拍照或选择照片并提交时，保存作业照片，供本家庭家长查看、反馈和确认学习完成情况。 |
| 麦克风／录音信息 | 在用户主动开始录音并提交时，保存朗读作业，供本家庭家长播放、反馈和确认学习完成情况。 |
| 摄像头（后台要求时） | 在用户主动拍照时拍摄作业内容，供用户选择并提交给本家庭家长。 |

补充文档同步说明：孩子账号由监护人绑定，只能访问绑定档案；附件私有存储，仅供该孩子和家庭家长使用；无自动评分或公开分享；保留期限和删除途径见指引。具体信息类型和审核结果以后台展示为准。

## 验收

`tests/homework.test.js` 覆盖角色与档案绑定、旧接口越权、照片／录音提交、家长退回和确认、完成撤销、重复请求、过期审核、附件隔离、缓存清理和录音生命周期。`tests/api-contract.test.js` 保持旧数据读写兼容验证。

真机需使用两个独立微信账号验证：孩子绑定→录音及拍照→提交后仍未完成→家长播放／查看→确认→孩子刷新看到完成；再验证退回、权限拒绝和移除成员。自动化内存测试和浏览器渲染不能替代真机媒体验收。
