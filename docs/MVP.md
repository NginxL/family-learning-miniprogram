## 数据与权限

一个微信账号在本版加入一个家庭。服务端身份为 `SHA256(OPENID)`，客户端传入身份不参与权限判断。保留家庭名称、成员称呼、孩子昵称、可选出生日期／年龄／在读年级和学习数据。出生日期以 `birthDate`（YYYY-MM-DD）保存，周岁按上海当天日期重算，生日当天零点增长一岁；离线缓存展示也使用同一规则。2 月 29 日出生者在平年 3 月 1 日增长一岁。未填生日的旧档案保留手填年龄和填写日期；在读年级单独维护，学习进度单独统计。

首次打开自动建立默认家庭及孩子档案，不显示创建表单；已有档案直接复用。正式入口的新档案统一使用「孩子」、6 岁、一年级、无生日，不读取私有 `DEFAULT_CHILD_*` 环境变量。真实昵称与生日由创建者在家庭页维护；旧数据库中的档案保持不变。家人管理默认折叠。只有一位成员的默认家庭可在使用有效邀请码并确认后切换到家人的家庭，原记录保留；退出或被移除后恢复自己的默认家庭，原家庭缓存和待同步操作清除。

「家庭 → 隐私与数据管理」说明账号标识、选填档案、学习记录、本地缓存、家庭权限及数据请求方式。导出、删除和注销由环境管理员核实权限后处理，页面提供微信反馈入口。

| 集合 | 主键／用途 |
|---|---|
| `profiles` | 用户身份摘要 → 当前家庭 |
| `families` | 家庭、创建者、最多 10 位成员、5 个孩子、100 条计划 |
| `invites` | 96 位随机邀请码摘要；24 小时、一次使用、新码撤销旧码 |
| `days` | 家庭＋上海日期摘要 → 当日任务快照及状态版本 |
| `receipts` | 用户＋操作编号摘要 → 操作指纹及回执，用于重试去重 |
| `learning` | 家庭＋孩子摘要 → 已安排内容、完成日期、家长掌握确认与版本 |
| `homeworks` | 家庭＋孩子＋日期＋类型摘要 → 最近一次作业、附件引用及审核版本 |
| `attachments` | 用户＋上传编号摘要 → 私有附件归属、大小、摘要和文件ID |

客户端数据库及云存储直接读写全部拒绝。所有请求经 `familyApi`，先检查成员关系。创建者负责邀请、移除和添加孩子；所有家长可以安排计划及确认学习。孩子角色由创建者通过指定档案的绑定码授予，只能读取自身档案及提交作业，不能改计划、完成、掌握或成员权限；服务端也拒绝孩子调用旧完成接口。创建者不能直接退出；家庭转让、合并待实现。

创建／加入家庭、成员修改、打卡、档案及回执写入均使用事务。孩子档案修改与掌握确认采用预期版本，拒绝覆盖已更新的数据。设备联网后发现成员已被移除时清理本机缓存；已合法下载的离线副本无法即时远程擦除。

## 任务与同步

按上海日期生成任务。「明日计划 → 任务模板」将古诗文、单词、句子、英文阅读和阅读的每日数量合并为一张卡，新学／复习及内容范围默认折叠；旧数学、其他的非零配置继续显示和编辑。明日页面展示所选孩子的全部类型任务，不继承其他页面的科目筛选；只有多个孩子时才显示切换栏。每个孩子最多10个命名模板，新建时复制当前数量配置。保存后在「自动安排」中选择每天使用的模板，或分别选择周一至周五与周末（周六、周日）的模板。未被安排使用的模板修改不改变日程。

星期安排按自然星期重复，不调整法定节假日或调休。`templateForDate` 使用目标学习日的上海日历日期，避免设备时区改变星期；周五的明日预览使用周六模板，后续再次生成时使用同一规则，不需要定时切换 `activeId`。英文阅读归属英语科目，内容由家长录入；已有阅读与句子记录保持原类型，不从标题猜测或迁移。全新排除过去已经安排过的内容（包括未完成）；复习仅选择完成过的内容，优先最近学习时间最早者。当前不采用 FSRS 或遗忘曲线预测。

`families.templateSets[childId]` 保存模板列表、每日默认 `activeId`、`revision` 及可选 `weeklySchedule`（`weekdaysTemplateId`、`weekendTemplateId`）。没有模板字段时，把旧 `autoPlans` 配置显示为「每日积累」，读取不迁移或重置数据；没有星期字段时继续每天使用默认模板。`saveTemplateSchedule` 以 `weeklySchedule: null` 恢复每天相同，星期安排只引用当前孩子已保存的模板。模板写入把默认规则镜像到 `autoPlans`，旧 `saveAutoPlans` 请求更新默认模板并保留星期安排；旧客户端不能编辑星期配置。

家长修改模板和星期安排共用该孩子的模板版本，冲突保留本地草稿并要求重新载入；`receipts.template` 保证同一操作重试不重复写入，旧回执指纹格式保持兼容。默认模板及被星期安排引用的模板均不能直接删除，须先调整使用安排。孩子仅查看所属档案的模板，不能修改。保存成功但后续刷新失败时，只接纳相同账号／角色／家庭中的较新模板，不覆盖其他家庭字段。

作品与具体学习单元分别识别：原作全文和教材节选不会重复当作全新作品。家长自建的同名片段或练习保持独立记录，不因标题相同而计入教材年级掌握；明确对应单一作品的标题仅用于保守排除重复新学。

当天首次读取时按孩子、类型生成并冻结。采用模板管理后，修改模板或星期安排保留今天已生成的任务，包括数量为零的类型；明日自动预览按目标日期对应的新模板计算。未采用模板管理的旧配置仍保持原接口语义：当天新启用的类型可以补入。数量设为零暂停对应类型；内容不足时展示缺额，不重复填满。底部「明日计划」默认展示次日按类型折叠的内容，展开后每批显示20项；「任务模板」和「添加任务」分别管理可复用规则与手动安排。

知识库内容可以加入今日、明日或今日起365天内的指定日期，同一孩子同日同内容去重。手动添加支持仅指定日期、从指定日期起每天固定、加入自动内容库；回顾仍可加入今日复习。旧请求省略 `date` 时沿用今日，旧每日计划省略 `startDate` 时保持每天重复。手动内容与自动数量叠加。

同日去重以孩子及内容身份为边界：内置作品的全文与节选合并安排；自建内容仅在类型、标题及正文相同时合并，保留大小写和正文差异。新学与普通单次添加过滤已完成内容；已预约到未来但提前学完的内容也会从未来预览中移除。主动复习及明确设置的每日固定任务保留重复学习语义。已完成的任务快照和掌握记录不因计划去重而删除或改写。

家长在「明日计划」展开任务后可选择「修改日期 / 删除」。`editPlannedTask` 仅接受未来未完成安排，目标日期为今日起365天内；移动与目标日期同内容合并。删除或改期仅作用于这一次，保留每日固定规则。`days.omitted` 保存日期内的排除项，自动任务移除时同步减少该日自动名额，刷新不会补回；主动重新添加仍可恢复安排。`days.planRevision` 防止多手机覆盖，`receipts.planning` 支持同一请求重试。修改源日、目标日及预约索引使用同一事务，接口不重写 `learning`，今日及过去的源日期不能调整。规则或学习状态变化使原预览任务失效时，拒绝旧请求并要求刷新。

未来手动内容保存于目标 `days`；`families.scheduledContents` 保存最多1000条未来预约，阻止自动规则提前选入已预约作品，过期预约在后续添加或调整时清理。已有当天任务保持不变。查看未来日期时先生成当天真实任务，再用独立档案副本推算目标日自动内容；预览不保存未来自动任务，也不写入 `learning`。明日自动内容会随今日学习和规则变化，明天首次读取时固定。这里只推算目标日，不模拟中间日期的自动学习。

未来日期不能打卡或提交作业；服务端的安排日期校验与完成日期校验独立。孩子只读自身明日安排，仍由家长设置计划。数学从知识库的可选列表及筛选中移除，旧数学ID、完成记录及已有自建／自动规则保留兼容。古诗文朝代和作者通过内容ID在页面补充，不重写旧任务正文与学习身份。

暂停影响后续生成，当天任务和历史保留。未生成过任务的日期不补造历史；支持近一年已生成日期记录的查询及补记，知识回顾通过持久化档案跨日期汇总。升级旧版记录的索引边界见[部署说明](DEPLOYMENT.md)。

今日的全部及科目视图按类型显示摘要卡片；点击整张卡片进入 `pages/study/index`，查看任务快照中的正文、来源与备注。卡片上的完成／撤销按钮独立响应，不触发跳转。详情页每批展示 20 项，点击继续展示后保留当前位置；底部按钮始终操作完整类型组，包含尚未展开的内容。部分完成时只补记剩余项，全部完成时可整组撤销，不增加逐项打卡入口。顶部进度和科目数量按学习类型统计，回顾及知识进度仍按具体内容统计。

详情页固定打开时的家庭、孩子、日期与类型；跨午夜和全局导航变化不改变目标记录。刷新后家庭或孩子不再匹配时清空内容并引导返回，不自动切换到其他档案。查看详情不新增学习记录；返回今日时重新读取同一同步队列中的状态。页面隐藏或关闭时移除刷新定时器与同步订阅。

孩子在详情页提交照片或录音后，由家长确认才计入学习完成。提交、审核及附件权限详见[角色与作业](HOMEWORK.md)。

家长整组打卡／撤销先校验任务与队列容量，一次持久化全部本地变更，再逐项顺序提交；本地存储失败时整组不变。云端沿用每个任务独立的事务、操作编号和预期版本，不是整组事务；部分同步完成时其余项继续显示待同步。断网、超时和“服务器成功但响应丢失”可重试。重复编号表达不同意图会被拒绝。

打卡不自动视为掌握。家长可确认已掌握、改为还需巩固；撤销最后一个学习日的完成记录会清除掌握状态。内置内容在知识档案保存 ID 引用，日任务保留原始正文快照；档案和日快照超过 700 KiB 会原子拒绝写入，要求扩容，禁止静默丢弃历史。

并发修改同一项时只接受版本匹配操作。冲突操作及其后续本地连锁操作清除，展示提示，保留服务器状态供家长重新确认。不同任务互不覆盖。

打开小程序、恢复网络、打卡与前台每 20 秒触发同步；后台／锁屏不保证运行。本地缓存 30 个日期、8 页回顾、5 个孩子进度、最多 500 条待同步操作。家庭管理、计划编辑、掌握确认要求联网；离线支持内置知识库、已缓存记录和家长任务打卡；孩子作业提交要求联网。家庭／账号、角色或绑定档案切换清除相关缓存，过期响应不能恢复前一家庭的数据。
