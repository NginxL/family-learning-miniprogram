## 播放与复用

播放顺序为手机文件、家庭私有云音频、首次合成。下载或合成成功后自动保存，不需要保存按钮。普通停止、切页、隔天或重启小程序均不主动删除有效文件，也不按时间过期。手机已有文件时直接播放，不请求云函数。

正文以实际朗读段落为准。英文词义、来源说明等不参与朗读的内容变化不会触发重新生成；正文、语言、音色、语速、采样率或合成版本变化才使用新音频。日期、今日任务编号和进入页面不影响同一音频的复用。

手机缓存按微信账号摘要、家庭、角色与孩子档案隔离。文件名使用摘要，保存时不以明文学习文本命名；读取时校验大小和音频摘要。微信卸载、用户清理小程序数据或系统清理仍可能移除文件，无法保证只有卸载微信才丢失缓存。手机文件缺失或损坏时从云端取回；云端副本损坏或不可读时报告错误，不静默重复合成。

手机缓存保护上限128MiB。达到上限或写入失败时保留此前的有效文件，新增音频尝试临时播放，并提示未保存在手机；云端副本仍可复用。容量限制不会触发自动购买、扩容或删除旧音频。主动退出家庭或切换账号后，原身份的文件不再参与播放；旧离线副本无法远程擦除，可通过微信清理小程序数据移除。

## 云端权限、并发与费用

音频位于现有环境的私有`speech/v1/`目录，`speechAudio`集合只允许管理员读写。客户端不能自行指定任意合成正文或文件ID，也不获得公开下载链接。云函数先核验微信身份、家庭成员关系及孩子访问权限，再从有权访问的学习内容中提取正文；下载结束后再次核验权限。

同一家庭、正文和音色使用稳定记录键。数据库事务为首次合成登记租约和预留额度，避免多个云函数实例同时合成。合成完成、上传前暂存音频；上传失败后重试复用中间结果，不重新扣合成字符。成功保存后删除数据库中的音频中间数据。若合成请求结果不明，或进程在结果尚未持久保存时中断，预留字符不退还；不能保证这种异常下绝对只调用一次供应商。

现有合成保护继续生效：总计100万字符、每家庭每日1万字符、供应商后付费关闭、免费资源到期即停止新合成。云缓存与手机缓存命中均不占新合成字符。另设256MiB云音频容量和每日256MiB下载保护；额度按双口音库实测及导入回读调整，手机缓存仍为128MiB。这些是应用保护上限，不是套餐赠送容量。云存储、数据库、函数执行和传输共用环境已有资源点，环境超限按量必须保持关闭。资源耗尽或套餐到期可能影响云端下载，但手机已有音频仍可播放。

费用依据：[CloudBase套餐说明](https://cloud.tencent.com/document/product/876/136006)、[超限设置](https://cloud.tencent.com/document/product/876/46895)。账号用量存在统计延迟，不将查询时的剩余额度解释为无限可用。

## 测试版与发布

2026-10-24账号持有人确认最新测试版正常。1.4.0已上传并由账号持有人确认“审核中”；87个固定文件与已验收预览一致，368项测试通过。候选包沿用`familySpeechPreview`处理朗读请求，名称保持不变；未重新部署函数。后台提审资料已准备持久音频用途及1.4.0隐私补充文档，具体字段未由工具读取。正式发布状态及发布后的专项验收待确认，见[发布记录](RELEASE.md)。

2026-10-22测试代码固定为`280d1db`。`npm run build && npm run verify`通过345项测试、类型检查、219个JS/JSON文件检查。独立函数`familySpeechPreview`状态为Active，部署回读6,098个文件与固定产物一致。集合`speechAudio`为ADMINONLY，云存储读写规则仍为false；未开启超限付费或自动续费。官方CLI预览成功，包体1,655,884字节，没有上传新的审核版本。

真实合成和云存储验证使用隔离的测试身份，未读写家庭档案、任务或历史记录。单词音频为4,032字节，跨实例读取及模拟合成到期后内容一致；测试云文件与临时记录已删除，实际用量计数保留。真机自动缓存、再次启动播放和跨手机复用仍待验收。

测试版只将`getSpeech`请求路由到`familySpeechPreview`，家庭、任务、学习记录及同步仍使用已有`familyApi`。新函数只接受朗读动作，不接受创建家庭或修改学习记录。旧客户端的API请求和返回结构不变；未配置独立语音函数时兼容原朗读接口，但不能据此认定云端已启用持久缓存。

配置独立函数使用`npm run configure -- --appid <AppID> --env <环境ID> --speech-function familySpeechPreview`；机器专用配置不进入Git。函数处理入口为`speech-index.main`，需要现有TTS私有配置及`SPEECH_STORAGE_INCLUDED_ONLY=true`。该开关只能在确认现有套餐可用、超限付费关闭后启用。不要给函数添加HTTP触发器、预置并发、公开文件权限或付费资源。

1.4.0提审材料说明音频会保存至手机和受权限保护的云存储，按正文与音色复用，公开预生成音频经权限核验可由不同家庭复用，家庭自建内容按家庭隔离。费用计数不保存正文；管理员可处理家庭音频与中间记录删除。客户端使用新的首次朗读同意提示和隐私页面，1.3.0历史材料保持原样。

验收：播放一首诗或单词后关闭小程序并重新打开；再次播放应直接使用手机文件。另一台手机首次播放相同内容应读取已有云音频，不增加合成字符。同步、历史完成记录、孩子权限和退出页面停止播放应保持原行为。正文或音色变更、缓存缺失、断网及空间不足分别验证。
