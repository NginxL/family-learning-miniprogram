## 2. 英语词典来源与复核方法

| 来源 | 数量 | 可复核对象 |
| --- | ---: | --- |
| [Open English Wordnet 2025](https://github.com/globalwordnet/english-wordnet/releases/tag/2025-edition) | 913词、1708个所选义项 | 每义记录sense ID、synset、词性、中文短释义和英文定义SHA-256；原始压缩包固定SHA-256 |
| Collins、Cambridge、British Council | 69词及部分补充义 | 逐条具名词条／语法页链接，用于介词、代词、情态动词等及需要更准确区分的用法；mine另引用1个Wordnet名词义 |
| 已有多义词补审 | 18词 | 既有来源与释义保留，未被新增数据覆盖 |

中文释义是选择义项后的简短改编，不是词典全文、频率排名或全部用法。教材义仍按原书照录，词卡的教材年级与单元映射没有随词典补充改变。

[官方XML压缩包](https://en-word.net/static/english-wordnet-2025.xml.gz) SHA-256：`9ca6d1dcb75f822fdd66617f7d9da48142ace38dd544d6ad5e2feca1674ad3fe`。下载到本地后可运行：

```sh
python3 scripts/verify-wordnet-evidence.py /path/to/english-wordnet-2025.xml.gz
```

该命令已通过1708个义项及1个补充义定位检查，核对文件版本、词性、定义哈希；不联网、不改知识数据。它验证引用能回到原始定义，不能代替中文释义的语义和教学审查。

Open English Wordnet采用CC BY 4.0并保留Princeton WordNet声明。署名、改编说明和完整许可同时保存在[数据说明](../data/catalogs/README.md)、`licenses/`、小程序及云函数的`THIRD_PARTY_NOTICES.txt`中。现代教材扫描页、词典整库、现代课文和音频不在公开仓库中。
